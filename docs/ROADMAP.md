# Website Roadmap

## Gate 0 — Business truth
Lock business name, coach identity, credentials, locations, schedule, pricing, WhatsApp and policies.

## Gate 1 — Brand assets
Receive final logo, approved photography and written brand usage rules.

## Gate 2 — UX prototype
Approve desktop + mobile home, programs, locations, coach, pricing and conversion surfaces.

## Gate 3 — Application baseline
Create Next.js application with TypeScript strict mode, linting, tests, i18n and CI.

## Gate 4 — Content and local SEO
Metadata, sitemap, robots, LocalBusiness schema, bilingual content, location pages and NAP discipline.

## Gate 5 — Conversion
WhatsApp deep links, trial request flow, UTM capture, analytics and conversion events.

## Gate 6 — QA
Build, tests, browser flows, accessibility, performance, responsive screenshots and content-truth review.

## Gate 7 — Production
Vercel deployment, exact-SHA verification, domain wiring, final smoke test.

## Gate 8 — Growth
Google Business, review acquisition, content cadence, landing pages and paid campaigns only after destination quality is proven.

### No fake closure
“Implemented” means code exists.  
“Verified” means evidence exists.  
“Production-ready” means every required gate above is demonstrated.
